# Barbearia VH

Site institucional de uma barbearia fictícia, feito para praticar HTML, CSS e JavaScript.

> **Projeto de demonstração:** endereço, telefone e demais dados do site são fictícios.

## O que o site tem

- Página única com as seções **Serviços** e **Contato**
- Menu fixo no topo com rolagem suave entre as seções
- Destaque no menu da seção que está na tela
- Menu em formato de botão (☰) para celular
- Cartões de serviço com efeito ao passar o mouse
- Animações de entrada na página
- Layout que se adapta a telas pequenas

## Tecnologias

- HTML5
- CSS3 (variáveis, grid, transições e animações)
- JavaScript (menu para celular e `IntersectionObserver` para destacar a seção atual)

## Como abrir

Baixe os arquivos e abra o `index.html` no navegador. Não precisa instalar nada.

## Estrutura

```
index.html   # estrutura e conteúdo da página
style.css    # estilos e animações
script.js    # comportamento do menu
```
